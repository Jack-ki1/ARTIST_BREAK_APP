# Security Policy

## Reporting a vulnerability

Please report suspected security vulnerabilities privately by emailing the maintainers or by opening a private security advisory through the repository's security tab.

Do not disclose issues publicly until a fix is available and the maintainers have confirmed the scope and remediation plan.

## Supported versions

This project is under active development. Security fixes are prioritized for the currently tracked default branch.

## Operational guidance

- Keep the API bound to localhost or a trusted network during development.
- Do not expose demo sign-in or unauthenticated APIs to public traffic.
- Rotate credentials for any external provider integrations before production use.
