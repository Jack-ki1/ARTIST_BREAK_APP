# Scoring method

The scoring model is intentionally conservative. The system should support explainable, human-reviewed decisions instead of opaque ranking output.

## Principles

- Score components must map to explicit evidence rows.
- Each score must indicate what was measured and which source contributed it.
- Human review remains the final decision authority.

## Planned rubric

- songwriting
- melody and hook strength
- vocals
- production and arrangement
- originality
- live potential
- market fit

Each rubric item should be reviewed with comments, timestamps, and reviewer identity.
